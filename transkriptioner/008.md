# 008.jpg

**Dokumenttyp:** Fortsättning av 007.jpg – lagfartsutdraget från 1848. 5:o-punkten (fastebref 1812) avslutas, därefter ett citerat utdrag ur jordeboken och mantalslängden för 1848 i tabellform. Sidan saknar stämpel och sigill.

Till höger i bilden syns kanten av nästa blad (009); transkriberas inte här.

## Transkription

```
1   Matts Jacobssöner Sand=
2   nabba den 3. April 1812.
3   utfärdade fastebref
4   å fem tjugufjerdedels
5   mantal af Sandnabba
6   Skatte hemman N:o 24.
7   i Öfverpurmo by, samt
8   i bestyrkt afskrift
9   ett af Herr Härads=
10  skrifvaren Gabriel
11  Palmquist uthändi=
12  gadt sålydande bevis:
13  Utdrag af Jordebo=
14  ken och mantals Läng=
15  den för Pedersö Socken
16  i Korsholms Norra
17  Härad för år 1848.
```

Tabell (rad 18–22). Kolumnrubrikerna står i två nivåer; underrubrikerna för nummer, mantal och mantalsdelar är skrivna lodrätt:

```
18  Bya namn. | hemmans nummer: ny. / gammal. | mantal: Skatte / [Tillökt?] Krono | hemmans Namn.: nu gällande / Förut gällande | Åboernes Namn. | Mantals delar: Skatte / Krono.
19  Öfverpurmo | 8 | 24. | 1/4 | 1/6 | Sandnabba | Sandnabba | Jacob Jacobsson | 1/16 | 1/24
20  | | | | | | | Jacob Mattsson | 1/16 | 1/24
21  | | | | | | | Simon Johansson | 1/16 | 1/24
22  | | | | | | | Eric Johansson | 1/16 | 1/24
```

```
23  Rätteligen utdragit be=
24  ./.
```

Anmärkningar:
- Rad 1 fortsätter direkt från 007 rad 24 ("Bönderne Hans och / Matts Jacobssöner").
- Rad 2: dagen "3." har den platta 3-formen (ʒ).
- Rad 6: "N:o" med upphöjt, understruket o.
- Tabellen: under de lodräta rubrikerna "Skatte" och "Krono." i sista kolumnen står ett tecken "⅟." (bråkstreck med punkt), troligen en markering för "del". Bråken i tabellen är skrivna lodrätt (täljare över nämnare).
- Rad 23 ("Rätteligen utdragit be=") står under tabellen och fortsätter på 009 rad 1 ("styrker").
- Rad 24 är ett fortsättningstecken ("./.") längst ner till höger.
- Långt s (ſ) och c med krok ("ç") som tidigare; återgivet som s resp. c.

| 18 | `[Tillökt?] Krono` | Lodrätt rubrik i trång cell, skriven i två rader. Första ordet ser ut som "Tulöpt"/"Tillökt". "Tillökt Krono" (tillökt kronomantal) stöds av beslutet i 010 rad 10–12 ("tillökt med ett tjugufjerdedels mantal krono"). |
